# AdTech Campaign Analytics Platform
SinglePage Web App: React/Redux
Terraform: AWS CICD with CodePipeline, CodeBuild, ECS and a Springboot App
Hybrid persistency layer (PostgreSQL, DynamoDB for high scale data ingestion)

See the system diagram [here](https://htmlpreview.github.io/?https://github.com/garygz/dsp-demo-project/blob/main/docs/architecture/diagrams/SystemDiagram-Apr-2026.html).
## Description

AdTech Campaign Analytics Platform - provides an example of SpringBoot + Hybrid persistency/data ingestion layer (RDBS+DynamoDB) to allow for highly scalable
and unpredictable data ingestion loads.
