AdTech High-Scale Platform

AWS ALB → ECS/EC2 → Spring Boot API with dual-path data flow
Edge & Routing ALB terminates TLS and routes by path. CRUD traffic and ingestion traffic are split at L7 so they can scale independently.
CRUD Path (blue) /advertisers and /campaigns — low QPS, relational. Spring Boot → JPA → RDS PostgreSQL.
Ingestion Path (purple) /events, /impressions, /clicks — high QPS, write-heavy. Spring Boot → DynamoDB on-demand for flat scaling.
Aggregation (green) A Spring @Scheduled job runs every 30s, rolls up raw events from DynamoDB, and UPSERTs aggregated counters into Postgres for reporting.
